# Native fonts

Cantarell Regular is an unmodified copy from the host Fedora `abattis-cantarell-fonts` package, distributed under the SIL Open Font License included in `Cantarell-LICENSE`. It is the primary UI family, matching the Linux workstation mockups.

Cantarell is embedded in the native executable. Default egui fonts remain available for monospace text and symbol fallback. Their notices are retained in the packaged dependency licenses. No runtime font download or dependency on the host font package is required.

The application interface uses English. Chinese translation catalogs and dedicated CJK font assets were retired; retained user text and protocol data are never rewritten.
