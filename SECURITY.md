# Security

GP200 Linux is under active development. Security fixes target the current main branch; there is no maintained stable release series yet.

If GitHub private vulnerability reporting is enabled for this repository, use **Security → Report a vulnerability**. If it is unavailable, contact the repository owner through an existing private channel, or open an issue requesting a private reporting channel without posting exploit details or sensitive files.

Include the affected version or commit, the relevant workflow, reproduction steps and the likely impact. A small synthetic reproducer is preferable to a personal preset or device capture.

Do not post private presets, audio, full device banks, raw USB/MIDI captures, secrets or unredacted logs in public issues. Review support archives before sharing them; explicitly attached files can contain your original data. The application creates support archives locally and does not submit them automatically.

Report reproducible memory/resource exhaustion, unsafe file handling, unintended device operations or leaks of private data. Ordinary feature requests and device compatibility reports belong in issues.
