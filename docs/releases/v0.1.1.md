Fixes a pedal connection failure after reboot that affected both the AppImage and native builds.

Completed firmware recovery history in v0.1.0 could retain a filesystem device number that changes after reboot on Btrfs. The app then refused connection with `Linked exact file identity/extent differs`, even though the recovery files were intact. Version 0.1.1 validates completed history against the currently opened registry filesystem while preserving inode, content, journal and complete-set checks. Unresolved attempts still block connection, and live recovery identity checks remain enforced.

Upgrade the application and reconnect normally. Keep your existing library, firmware history and journals; another firmware update is not needed for this fix.

### Downloads

- **AppImage:** `GP200-Linux-0.1.1-x86_64.AppImage`; make it executable and launch it. Use `--appimage-extract-and-run` if FUSE is unavailable.
- **Portable archive:** `GP200-Linux-0.1.1-x86_64.tar.gz`; extract it and follow its installation instructions.
- Verify downloads against **SHA256SUMS**.

These preview packages target Linux x86_64 with Ubuntu 24.04 or a compatible runtime: glibc 2.39 or newer, ALSA, a compatible C++ runtime, Mesa/OpenGL, and a Wayland or X11 desktop.

### Validation and firmware scope

The reboot regression reproduced the original failure before the fix. All 29 targeted recovery/registry tests passed afterward. A locally built 0.1.1 AppImage from the fixed source connected to a physical GP-200 running V1.8.2 and read its current preset and global settings. The installed AppImage was also checked with the existing user configuration. No pedal settings were written, and the original recovery history and successful journal remained byte-identical.

The downloadable GitHub packages are separate CI builds of this source, with hardware-free tests, native simulator checks, package checks and checksum verification. They have not themselves been used for a firmware update.

The previously tested firmware path remains **GP-200 V1.6.3 → V1.8.2**, including full-image recovery after interrupted attempts. Firmware images are not included. Broader device/version coverage, full official-editor parity, complete sound backup/restore and physical IR/SnapTone transfers remain unfinished. See the [README](https://github.com/geordyd/gp200-linux#readme) and [firmware guide](https://github.com/geordyd/gp200-linux/blob/v0.1.1/docs/firmware.md).
